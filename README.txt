CALCPRO WEBSITE STARTER
=======================

FILES
- index.html: homepage and six working calculators
- css/style.css: responsive styling
- js/script.js: calculator logic and navigation
- about.html, privacy-policy.html, terms.html: supporting pages
- robots.txt and sitemap.xml: basic SEO files

RUN LOCALLY
1. Extract the ZIP.
2. Open the folder in Visual Studio Code.
3. Install the Live Server extension, or run a local static server.
4. Open index.html using Live Server.

BEFORE PUBLISHING
1. Buy a domain and deploy the folder to a static host such as Netlify.
2. Replace https://YOUR-DOMAIN.example in canonical URLs, sitemap.xml and robots.txt.
3. Replace the placeholder email in privacy-policy.html and terms.html.
4. Add your actual contact details and publication dates.
5. Review and customize the privacy policy to match the actual services, cookies, analytics,
   advertising and data handling on your site. The included text is a starter, not legal advice.
6. Add a favicon and any original branding/assets you want.
7. Test every calculator, page, navigation link and mobile layout.
8. Add your site to your existing AdSense account. Only then paste the exact AdSense code
   Google provides into the head of each page (or use a shared template).
9. Add ads.txt only with the exact line shown in your AdSense account.
10. Submit the live site for review. AdSense approval is not guaranteed.

ADSENSE NOTE
The AdSense script in index.html is intentionally commented out and contains a placeholder.
Do not publish the sample publisher ID. Use the exact code from your AdSense account after
you add and verify your domain. Do not click your own ads or encourage others to click them.

CALCULATION NOTES
- EMI: standard reducing-balance monthly payment estimate.
- GST: add GST or extract tax from a tax-inclusive amount.
- SIP: monthly contributions at month-end with monthly compounding; estimated only.
- Age: calendar-based years, months and days.
- Percentage: X% of Y and optional part-as-percent-of-total.
- Discount: original price less percentage discount.


ADDED FEATURES
- Share result: uses the browser share dialog when available; otherwise copies the result text.
- Download result: downloads the active calculator result as a text file.
- Dark mode: site-wide toggle in the header, saved in the browser for future visits.
